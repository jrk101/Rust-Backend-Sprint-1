# Individual Practice Zone

This is where each student learns and experiments before a rotating group
applies the work to the one shared product in `../shared/`.

| Student ID | Personal workspace |
|---|---|
| RB01 | [practice/RB01](RB01/README.md) |
| RB02 | [practice/RB02](RB02/README.md) |
| RB03 | [practice/RB03](RB03/README.md) |

Each workspace has `unit-01` through `unit-17`. Open the current unit's
`problem_statement.md` for a link to the canonical tasks in `../units/`.
Create the files and Rust crates named by those tasks inside your own unit
folder. Do not edit another student's folder or treat a practice solution as
the shared PayHook implementation.

`fixtures/unit-02-ownership/` is a common exercise supplied for Unit 2. Its
Rust code is deliberately broken so students can diagnose the ownership
error. It is not RB02's work and is not a completed Unit 2 solution.
