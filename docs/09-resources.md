# Learning Resources — Routing Guide

Links should be checked immediately before publication. Prefer primary sources
for version-sensitive material.

## Rust Core

- The Rust Programming Language (“The Rust Book”): ownership, structs, enums,
  errors, generics, traits, lifetimes, tests, iterators, closures, and smart pointers.
- Rust by Example for short syntax reinforcement.
- Rust standard-library documentation for exact APIs and guarantees.
- Cargo Book for workspaces, features, profiles, and package layout.

## Async and backend

- Tokio tutorial and Tokio API documentation.
- Axum documentation and official examples.
- Rust `Future` documentation for the core abstraction.
- HTTP Semantics specification sections relevant to methods, status codes,
  headers, retries, and idempotency.
- Tower documentation when middleware and load-shedding concepts arrive.

## Database and backend systems

- PostgreSQL documentation for constraints, transactions, indexes, locking,
  `SKIP LOCKED`, and query plans.
- SQLx documentation and repository examples.
- Argon2 crate documentation and OWASP password-storage guidance.
- Redis documentation only for the optional bounded lab.

## Engineering and delivery

- Pro Git and GitHub pull-request documentation.
- Rust API Guidelines where relevant to public module design.
- `tracing` and `tracing-subscriber` documentation.
- Docker and Docker Compose documentation.
- GitHub Actions documentation if GitHub is selected for hosting.
- OWASP material for webhook validation, SSRF, secret management, and logging.

## Resource rule

Each unit's final publication must link to exact chapters or pages rather than
“read the docs.” Students should know what to learn, why it is needed now, and
which task proves they can use it.
